# Learning Playwright Batch

Repository containing Playwright learning exercises and examples used in the LearningPlaywrightBatch course.

Structure:

- `chapter_01_basics/` — basic JS examples and setup checks
- `chapter_02_java_Concepts/` — placeholder for Java concepts

Quick start:

1. Install dependencies (if any):

```powershell
npm install
```

2. Run examples from `chapter_01_basics` with Node.js:

```powershell
node chapter_01_basics/03_verify_setup.js
```
